# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security issue in NetPulse, please do not open a public issue on GitHub. Public disclosure before an issue is patched puts users at risk.

Instead, please report security concerns via private GitHub Security Advisory or by contacting the project maintainers through private repository channels.

When reporting an issue, please include:
- A description of the vulnerability and attack vector.
- Reproduction steps or proof of concept.
- Affected components (telemetry, DNS cache, QoS policies, web API).
- Any recommended remediation steps.
